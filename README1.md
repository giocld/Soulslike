# Unity Souls-Like Guide Documentation

This folder contains documentation derived from a Unity tutorial series about building a Souls-like game. The source material is the transcript set in `rawvid/`. The documents here organize the systems, requirements, and design into standard formats for an assignment (README, full text description, SRS, and SDD), plus a categorized index of the transcript files.

## Contents

- `FULL_DOCUMENTATION.md` - comprehensive textual explanation of the game systems and how they fit together
- `SRS.md` - Software Requirements Specification
- `SDD.md` - Software Design Description
- `FILE_CATEGORIES.md` - categorized index of transcripts with a summary per category
- `rawvid/` - English TTML transcripts (source)

## Scope and assumptions

- The docs describe a single-player Souls-like prototype built in Unity.
- The guide focuses on gameplay systems, UI, AI, and progression, not on world building or narrative.
- Implementation details are inferred from transcripts and episode titles; there is no source code in this folder.

## How to use

1. Start with `FULL_DOCUMENTATION.md` for a complete overview.
2. Use `SRS.md` for requirements and acceptance criteria.
3. Use `SDD.md` for architecture and component design.
4. Use `FILE_CATEGORIES.md` to locate which episodes cover specific subsystems.

## Source

Transcript files live in `rawvid/` and are named after the tutorial episodes.
